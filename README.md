# Cars Dealership Review Application

**Project:** Cars Dealership Review Application  
**Course:** IBM Cloud Native Full Stack Development Capstone (Coursera)  
**Repository status:** In progress

## Project Overview

This repository contains the starter project for a full-stack car dealership application. The goal is to let users browse dealerships, filter dealerships by state, review dealership details, and submit reviews. The capstone also covers authentication, sentiment analysis, testing, continuous integration, and cloud deployment.

The project is being developed incrementally as part of the IBM Cloud Native Full Stack Development Capstone. Features and deployment evidence will be added as the corresponding tasks are completed.

## Technology Stack

- **Frontend:** React, JavaScript, HTML, and CSS
- **Backend:** Django (Python)
- **Dealership data service:** Node.js and MongoDB
- **Sentiment analysis:** Python microservice
- **Deployment workflow:** Docker, Kubernetes, IBM Cloud Code Engine, and GitHub Actions (as covered by the capstone)

## Repository Structure

- `server/djangoproj/` — Django project configuration
- `server/djangoapp/` — Django application code and API integration
- `server/frontend/` — React frontend and static pages
- `server/database/` — Dealership and review data service
